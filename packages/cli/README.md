# @hola/cli

A React + Ink CLI for Hola. Initially focused on deployment flows to speed up API testing.

## Dev

- Run in dev: `bun --cwd packages/cli dev`
- Build: `bun --cwd packages/cli build`
- Typecheck: `bun --cwd packages/cli typecheck`

## Env

- `HOLA_API_URL` (default `http://localhost:3001`)
- `HOLA_TOKEN` (optional)
